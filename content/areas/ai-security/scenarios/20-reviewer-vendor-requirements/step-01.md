## Start from the way out

An AI agent becomes risky when one path through it touches three things: content the
public can write, records that are private, and a way to send data outside. Security
people call this the lethal trifecta.

You do not need to read code to review it. Ask the vendor to draw every path from a
public input to an outgoing message or web request, and to mark which steps read
private records.
