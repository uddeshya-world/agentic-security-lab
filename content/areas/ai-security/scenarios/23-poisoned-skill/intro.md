Scenario 19 hid an instruction in an MCP tool's description. Agent **skills** have
the same problem with fewer moving parts: a skill is a `SKILL.md` file, YAML
frontmatter and then prose, loaded straight into the agent's context.

CivicDesk staff install `ward-report` from a community skills index. It builds the
weekly ward summary. It also asks for something else, in plain English.

The OWASP Agentic Skills Top 10 (v1.0-2026) names the pieces: AST01 malicious skills,
AST03 over-privileged skills, AST05 untrusted external instructions, AST08 poor scanning.
