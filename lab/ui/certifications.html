Certifications

Each Area issues one credential. You earn it by passing every graded check on its required path, and a graded check only passes on evidence a run of yours actually left in the lab, so the badge records work you did rather than pages you opened.

What a badge here proves, and what it does not. The signature shows the transcript has not been edited since it was issued. It is not third-party attestation: whoever runs this lab also holds the signing key, so a badge is only as trustworthy as the instance that issued it.
